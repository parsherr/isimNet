# Handoff Notes

Bir task bitmeden kesildiğinde veya bağlam sıfırlandığında sonraki oturuma aktarılacak bilgiler.

---

## Handoff Format

```
### [Task ID] — [Tarih]
- **Durum**: Nerede bırakıldı
- **Tamamlanan**: Yapılan işler
- **Bekleyen**: Yarım kalan / yapılacaklar
- **Engeller**: Bilinen blokerlar
- **Kritik bağlam**: Sonraki agent'ın bilmesi gereken
```
